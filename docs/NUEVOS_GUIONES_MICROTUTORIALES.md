## 16. Guión: Cómo aplicar un descuento a la venta

### VERSIÓN MOBILE (APP)

Hola. Te voy a mostrar cómo aplicar un descuento en una venta.
Primero, abrí la pantalla de Facturación con la caja abierta y agregá los productos del pedido.
Una vez que tenés los productos cargados, buscá el campo "Descuento" que aparece debajo de la lista de artículos.
Tocá ese campo y escribí el porcentaje que querés aplicar. Por ejemplo, si querés un 10% de descuento, escribí 10.
El sistema calcula automáticamente el monto descontado y te muestra el nuevo total.
Si preferís aplicar un monto fijo en vez de un porcentaje, buscá la opción para cambiar el tipo de descuento.
Listo. El descuento queda aplicado y se refleja en el comprobante final.

## 17. Guión: Cómo dividir el cobro entre varios métodos de pago

### VERSIÓN MOBILE (APP)

Hola. Te voy a mostrar cómo cobrar una venta usando más de un método de pago al mismo tiempo.
Con el pedido listo, tocá el botón "Cobrar" en la parte inferior de la pantalla.
Se abre la ventana de métodos de pago. Tocá el primer método, por ejemplo "Efectivo", e ingresá el monto parcial que el cliente te da con ese medio.
Después, tocá el botón "Agregar método" o el ícono "+" para sumar un segundo método.
Elegí el segundo método, por ejemplo "Tarjeta", y escribí el monto restante. QBITS calcula automáticamente cuánto falta cubrir.
Repetí el proceso si necesitás un tercer método.
Cuando la suma de todos los métodos iguale el total de la venta, el botón de confirmar se activa.
Tocá "Confirmar" y la venta queda registrada con todos los métodos de pago detallados.
Listo. Así podés cobrar con efectivo, tarjeta y transferencia en una misma venta.

Ahora, cuando cargués o editás un producto, vas a poder asignarle esa categoría.
Listo. Las categorías te ayudan a organizar tu catálogo y a filtrar productos más rápido cuando vendés.

Tocá "Guardar" y el stock del producto se actualiza de inmediato.
Listo. El ajuste queda registrado en el historial del producto para que puedas consultarlo después.

## 20. Guión: Cómo hacer un conteo de inventario

### VERSIÓN MOBILE (APP)

Hola. Te voy a mostrar cómo hacer un conteo de inventario en QBITS.
El conteo de inventario sirve para comparar lo que dice el sistema con lo que tenés físicamente en el depósito o las estanterías.
Desde el menú, tocá "Inventario" y buscá la opción "Conteo de Inventario" o "Recuento".
Tocá el botón para crear un nuevo conteo. Podés filtrar por categoría si querés contar solo una sección.
La app te muestra la lista de productos. Para cada uno, ingresá la cantidad real que contás físicamente.
No te apurés. El conteo queda guardado mientras lo completás y podés retomarlo después.
Cuando terminés de contar todo, revisá las diferencias. QBITS te marca en rojo los productos donde hay discrepancia.
Confirmá el conteo para aplicar los ajustes automáticamente. El stock del sistema se actualiza con los valores que contaste.
Listo. Ahora el inventario del sistema coincide con tu stock real.

## 22. Guión: Cómo ver los movimientos de un producto (Kardex)

### VERSIÓN MOBILE (APP)

Hola. Te voy a mostrar cómo consultar el historial de movimientos de un producto, también conocido como Kardex.

Desde el menú, tocá "Inventario" y buscá la opción "Kardex" o "Movimientos de Producto".
Buscá el producto que querés consultar y tocalo.
Se muestra una lista cronológica con cada movimiento: la fecha, el tipo de movimiento, la cantidad y el stock resultante después de cada operación.
Podés filtrar por rango de fechas para ver solo un período específico.
Si hay una diferencia de stock que no entendés, el Kardex es el lugar para investigarla.
Listo. Así tenés trazabilidad completa de cada producto.
