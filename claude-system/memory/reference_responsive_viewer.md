**Ubicación:** `/Users/leandro/libs/responsive-viewer/`
**Build:** `/Users/leandro/libs/responsive-viewer/build/` (listo para cargar en Chrome)

**Qué hace:** Muestra tu web en múltiples pantallas de dispositivos simultáneamente. Scroll y clicks sincronizados entre todos los viewports.

**Instalar en Chrome:**
1. Abrir `chrome://extensions`
2. Activar "Developer mode"
3. Click "Load unpacked"
4. Seleccionar `/Users/leandro/libs/responsive-viewer/build/`

**Chrome Web Store (alternativa):**
`chrome://extensions` → buscar "Responsive Viewer" (300k+ usuarios)

**Features:**
- Multi-screen preview (phones, tablets, laptops)
- Scroll y clicks sincronizados
- Screenshots con device mockups
- Custom screen sizes
- Open source (github.com/skmail/responsive-viewer)
